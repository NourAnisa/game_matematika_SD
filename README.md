# 🦁 Rimba Angka: Game Matematika Ceria Anak SD

> **Game Interaktif Edukasi Matematika untuk Anak Sekolah Dasar (SD Kelas 1 - 6) Berbasis Kurikulum Merdeka (Fase A, Fase B, dan Fase C).**

🌐 **Live Demo (GitHub Pages):** [https://nouranisa.github.io/game_matematika_SD/](https://nouranisa.github.io/game_matematika_SD/)

---

## 🌟 Fitur Utama Permainan

1. **🌱 Pilihan Fase & Kelas Sesuai Kurikulum Merdeka:**
   - **Fase A (Kelas 1 - 2 SD):** Penjumlahan dan pengurangan dasar (1–20) dilengkapi dengan **Bantuan Visual Apel 🍎** yang bisa dihitung satu per satu.
   - **Fase B (Kelas 3 - 4 SD):** Penjumlahan/pengurangan puluhan hingga ratusan, dan tabel perkalian 1–10.
   - **Fase C (Kelas 5 - 6 SD):** Operasi hitung campuran multi-digit, perkalian belasan, dan pembagian.

2. **5 Wahana Belajar yang Variatif & Ceria:**
   - **➕➖ Taman Berhitung Ceria:** Latihan operasi dasar berhitung dengan tombol jawaban 3D yang empuk dan ramah sentuhan jari anak.
   - **🎈 Pesta Balon Angka:** Mode ketangkasan memecahkan balon angka terbang dengan suara letusan balon (*pop!*) dan animasi bintang.
   - **🍕🔷 Kue Pecahan & Bangun Datar:** Belajar pecahan visual melalui potongan kue pizza serta mengenal bentuk-bentuk bangun datar geometri (Segitiga, Persegi, Persegi Panjang, Lingkaran).
   - **🛒📖 Petualangan Belanja (Soal Cerita):** Latihan literasi numerasi sehari-hari seperti menghitung sisa uang jajan di kantin sekolah, membagi buah hasil petik, dan menghitung pensil warna.
   - **⚡⏱️ Tantangan Kilat 60 Detik:** Mode berpacu dengan waktu 60 detik untuk mengasah kelincahan berhitung mental (*mental arithmetic*).

3. **📜 Generator Piagam Bintang Matematika (Sertifikat Resmi):**
   - Piagam penghargaan anak juara berbasis HTML5 Canvas 2D.
   - Nama anak dapat diisi sendiri dan piagam dapat langsung diunduh sebagai gambar **PNG** atau dicetak ke **PDF** untuk ditempel di dinding kamar atau portofolio tugas sekolah.

4. **🎵 Audio Synthesizer Ceria (Web Audio API):**
   - Melodi musik latar anak-anak (*nursery chime*) dan efek suara kartun lucu (*pop balon*, *chime sukses*, *boing*) tanpa ketergantungan file MP3 eksternal.

5. **📱 Desain Sangat Ramah Anak & Guru:**
   - Antarmuka ceria, warna cerah bersemangat, font jernih ramah anak (*Fredoka* & *Plus Jakarta Sans*).
   - Efek perayaan taburan *confetti* warna-warni saat menjawab benar.
   - Responsif sempurna untuk smartphone, tablet Android/iPad, laptop, maupun proyektor layar sentuh (*Smart Board*) kelas.

## 🚀 Cara Menjalankan Secara Mandiri (Lokal)

Cukup buka berkas `index.html` langsung di peramban web mana saja (Google Chrome, Edge, Safari, Firefox):

```bash
# Clone repositori
git clone https://github.com/NourAnisa/game_matematika_SD.git

# Masuk ke folder
cd game_matematika_SD

# Buka di browser
start index.html # (Di Windows)
# atau: open index.html (Di macOS)
```

---

## 🛠️ Teknologi yang Digunakan

- **HTML5 & Vanilla JavaScript ES6+** (Cepat, ringan, tanpa kompilasi/build step)
- **Tailwind CSS (CDN)** untuk tata letak modern dan ramah gawai
- **Web Audio API** untuk sintesis melodi ceria dan efek suara interaktif
- **HTML5 Canvas 2D** untuk piagam sertifikat dan partikel confetti
- **Local Storage API** untuk menyimpan perolehan bintang emas anak secara aman di perangkat lokal
